## 변경 후 검증

- Python 저장소/실제 HTTP 테스트 10개 통과: 기본 10문장, 수정·영속성, 과거 문장 사본, 학생별 기록/오답 분리, 미확인 상태, 입력 거부, 동시 저장, 접근 암호, 제품 화면, 비공개 파일/경로 탈출/비활성 AI API 차단.
- 음성 제어 Node 테스트 통과: 한국어 음성만 선택, 속도, 기본 두 번, 대기 중 일시정지·재개, 종료 후 예약/콜백 무효화, 합성 오류, 한국어 음성 없음.
- 제품 접근 암호 회귀 테스트 전체 통과: 쿠키, 잘못된 암호, 시도 제한, 임시 링크 만료, 정적 경로 보호.
- 원본 문자 정리 테스트 전체 통과.
- 원본 로컬 OCR/TTS 대역 12개 확인 통과. OS 음성 합성은 실행 환경에 say/powershell/espeak-ng가 없어 건너뜀.
- 원본 기록 테스트 --local 전체 통과. 해당 자동 채점 로직은 원본 회귀 테스트에만 사용하고 제품 서버에는 연결하지 않았다.
- 실제 server.py 프로세스 + Chromium Playwright 통과: 390px 휴대전화 / 820px 태블릿 / 1280px 화면에서 가로 넘침 없음, 10문장 표시·문장 수정·학생 등록/선택·한국어 속도/두 번 반복 제어·일시정지/재개·중지·부모 확인 저장·학생별 기록/오답 분리·오답 재연습·음성 없음 안내·서버 재시작 후 기록 유지. 브라우저 JavaScript 오류 없음.
- Playwright는 임시 데이터 폴더와 가상 음성 객체를 사용했다. 실제 소리/발음 검증은 아니다. 실제 브라우저의 기본 SpeechSynthesisVoice 타입에 맞춰 대역 생성자도 대체하여 검증했다.
- Python compileall 및 git diff --check 통과.
- LICENSE 변경 없음. data/, cache/, 음성 녹음이 Git 제외 규칙에 걸리는지 확인했다. 새 아이 사진·실명·비밀키는 추가하지 않았다.

## 남은 확인과 범위

- 사용자의 Android 태블릿 Chrome / iPad Safari에서 한국어 음성 설치, 실제 두 번 발화, 발음·음량·잠금/백그라운드·일시정지 동작을 확인해야 한다. 기기와 브라우저에 따라 음성 동작이 다르다.
- 외부 OCR/API·실제 사진 인식·AI 자동 채점은 실행하지 않았고 제품에도 연결하지 않았다. 원본 외부 통합 test_api.py는 1단계 검증 대상에서 제외했다.
- 부모 확인은 신규 기록 저장 시 제공한다. 과거 기록 수정·학생 관리/삭제·오답 숙달 처리·기존 중국어 기록 이관은 후속 단계다.
- 배포/원격 GitHub 업로드는 수행하지 않았다. 현재 결과는 이 작업 공간에 있으며 Test_wrt에 반영하려면 저장소 접근 권한을 연결해야 한다.
