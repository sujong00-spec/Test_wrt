# 단어쏙 — 공책 필기형 영어단어 시험 앱 (MVP v2)

## 아이가 실제 학원 시험을 준비하는 과정

1. 학원 단어장 사진을 인식하거나, 영어와 한국어 뜻을 붙여넣어 단어장을 만듭니다. OCR 인식 오탈자는 보호자가 검수합니다.
2. **시험**에서 `한글 → 영어` 방향을 선택하고 문제 수를 고릅니다.
3. 태블릿에는 한글 뜻만 한 문제씩 표시됩니다. 아이는 **공책에 번호와 영어 철자**를 씁니다. 화면에는 정답 입력란이나 정답이 없습니다.
4. 전 문제를 공책에 쓴 뒤 **채점하기**를 누르면 정답표가 나옵니다.
5. 보호자나 아이가 공책과 대조하여 **맞음/틀림**을 하나씩 표시하고 점수를 저장합니다.
6. 오답만 재시험해 암기를 마무리합니다.

## 포함된 기능

- 다수 단어장 생성·수정·삭제
- 샘플 영어단어 20개
- 사진 OCR (브라우저 내 Tesseract.js `eng+kor`, 초기 다운로드 필요)
- 엑셀/텍스트 복사 및 붙여넣기
- 발음·암기 카드
- 10/20/전체 문제 무작위 출제
- 한글→영어, 영어→한글 시험
- **노트 필기형 시험 + 시험 종료 후 정답표 대조 + 수동 점수 기록**
- 오답 재시험, 결과 기록, CSV 백업

## 작동 방식 및 개인정보

정답은 공책에 기록되므로 앱은 공책의 필기를 자동으로 인식하거나 자동 채점하지 않습니다. 정답표와 대조한 **수동 채점 결과**를 저장합니다. 사진 OCR은 인쇄된 학원 단어장을 입력할 때만 사용합니다. 사진을 서버로 업로드하지 않으며, 로컬 브라우저에서 인식합니다(엔진·언어 데이터를 내려받으므로 인터넷 연결 필요).

단어·시험 기록은 브라우저 `localStorage`에만 저장됩니다. 기기 간 동기화되지 않고 브라우저 데이터를 삭제하면 사라질 수 있어 CSV 백업을 권장합니다.

## 로컬 실행

`index.html`을 브라우저에서 열거나:

```bash
python3 -m http.server 8000
```

`http://localhost:8000`으로 접근합니다. 별도의 서버 API/계정은 필요 없습니다.
