# Codex 개발 지시문 — 단어쏙 공책 필기형 학원 영어시험

## 맥락

보호자의 초등학생 자녀가 학원에서 배부한 영단어 목록으로 시험을 준비한다. 아이는 태블릿에 영문 철자를 **입력하지 않는다**. 태블릿은 문제 제시/정답표 열람용이고 정답은 **실물 공책**에 쓴다. 최종 목적은 실제 학원 철자시험 대비다.

기존 `index.html`은 독립적으로 동작하는 정적 MVP다. 학원 단어장 OCR, 단어장 관리, 암기카드, 노트 시험, 수동 채점, 오답 재시험이 동작하도록 되어 있다.

## 절대 지킬 원칙

- 학생 답안은 공책에 씀. 시험 중 화면에 텍스트 입력창·정답·힌트를 제공하지 않는다.
- 시험 종료 후 정답표 공개. 보호자가 공책과 대조하여 맞음/틀림을 표기. 채점하지 않은 문항을 맞았다고 간주하지 않는다.
- 수동 채점을 "AI 자동 채점"이라고 부르지 않는다. 필기 사진 자동 채점은 정확도가 검증된 후 별도 기능으로 설계.
- 기존 받아쓰기 앱 `Test_wrt`의 `mobile-web/`, `server.py`, `core/` 등은 건드리지 않는다. 영어단어 앱은 독립된 별도 폴더에서만 개발.

## 다음 개발 순서 (우선순위)

1. 테스트 추가: 샘플 단어 20개, 노트 시험 10문제, 마지막 문제 뒤에만 답 공개, 모든 문항 수동 채점 완료 전 점수 저장 불가, 오답 재시험, 복습 정답 시 오답 목록 제거.
2. OCR 개선: 2열·3열 단어장 표 인식, 영어-한국어 쌍 미매칭 검토 UI, 잘못 인식된 줄 강조, 중복 검사 강화.
3. 실제 학원 시험 재현: 문제 순서를 시험지와 동일하게 또는 섞어서 선택, 문제 수, 공책 답안용 번호 일관성.
4. 오답 암기: 연속 정답 횟수, 시험 날짜별 약한 단어 추적, 오답만 반복 옵션.
5. 응시 중 실수 방지: 뒤로 가기, 앱 새로고침 후 진행 상태 복원, 마지막 채점 확인.
6. 부모/학생 모드(선택): 아이의 암기/시험에서 정답을 조기 노출하지 않는 UI.
7. 실제 학원 프린트 사진으로 OCR 품질 테스트(사진은 나중에 제공).

## 수용 기준

- 태블릿 360px, 768px 화면에서 가로 스크롤 없이 문제·채점 버튼 사용 가능.
- 시험 중 `정답 확인`이나 영문 입력필드가 나타나지 않는다.
- 모든 문제를 공책에 적은 뒤 채점 화면에서 정답을 일괄 열람한다.
- 맞음/틀림 전체 입력 전 결과 버튼은 비활성화다.
- 채점 저장 후 오답 목록/시험 이력이 일치하며 기존 데이터 로컬 저장소 호환성을 유지한다.
- 외부 LLM API 키 요구 없이 정적 웹앱을 실행할 수 있어야 한다.
- 정답 데이터와 학원자료의 사용자 동의 없는 외부 서비스 전송은 금지.
