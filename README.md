# 기량이의 받아쓰기 공부 · 한국어 받아쓰기

기량이 한 명이 종이에 받아쓰기를 하고 보호자가 직접 확인하는 모바일 웹앱입니다. 사용자 등록 없이 바로 연습합니다.

**바로 사용하기 → https://ttobak-dictation-mobile.constantcapybara1.chatgpt.site**

별도 설치 없이 휴대폰·태블릿 Chrome/Safari에서 열어 사용하세요. 카카오톡 안의 브라우저는 음성이 제한될 수 있으므로 ‘Chrome으로 열기’를 선택하세요.
ZIP은 개발 소스이며 휴대폰 설치 파일(APK)이 아닙니다. GitHub에 올린 것만으로 별도 서버가 생성되지는 않습니다.

## 기능

- 한국어 문장 10개 선택·수정, 기본 두 번 읽기, 속도·반복·쓰기 시간·일시정지 조절.
- 등록 없는 한 명용 연습, 학습 기록, 부모 직접 확인, 오답 복습.
- 모바일 배포판: ‘다 썼어요’ 수동 진행, 주차별 10문장 묶음 저장, 오답 최대 3문장 복습, 완료한 날의 스티커, 현재 문장 다시 읽기.
- 보호자 로그인은 선택 사항이며 계정별 동기화·백업·복원·기존 체험 기록 가져오기를 지원합니다. 인쇄 기능은 제외했습니다.
- 사진 OCR·사진 업로드·AI 자동 채점은 제공하지 않습니다. 확인하지 않은 답에 가짜 점수를 매기지 않습니다.

## 저장소 구성

| 경로 | 설명 |

| `server.py`, `core/`, `features/` | Python 표준 라이브러리로 실행하는 로컬 1단계 앱 |

두 실행 방식의 저장소는 별도이며 자동 동기화하지 않습니다. Python은 컴퓨터의 SQLite, 배포판은 로그인 계정별 서버 저장소 또는 익명 브라우저 저장소를 사용합니다.

## Python 실행

Python 3.10 이상이 필요하며 별도 패키지는 필요 없습니다.

```bash
git clone https://github.com/sujong00-spec/Test_wrt.git
cd Test_wrt
python3 server.py
```

컴퓨터 브라우저에서 http://127.0.0.1:8770/ 를 엽니다. 같은 Wi-Fi의 태블릿에서는 다음 명령으로 실행한 뒤 표시된 태블릿 주소를 여세요.

```bash
python3 server.py --host 0.0.0.0
```

## 모바일 배포판 빌드·검증

Node.js 24 이상을 권장합니다. 외부 npm 패키지는 필요 없습니다.

```bash
cd mobile-web
npm run build
npm test
node scripts/validate.mjs
```

이 코드는 Cloudflare Worker/Sites용 서버 API와 D1 저장소를 포함하므로 GitHub Pages만으로는 계정 동기화 기능을 실행할 수 없습니다. 호스팅 설정과 마이그레이션은 mobile-web/README.md를 참고하세요.
