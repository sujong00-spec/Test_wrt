# 기량이의 받아쓰기 공부 1.2

기량이 한 명이 종이에 쓰고 보호자가 직접 확인하는 모바일 웹앱입니다. 공개 주소는 유지합니다. 사진 OCR·자동 채점은 제공하지 않습니다.

기존 주소에서 사용합니다: https://ttobak-dictation-mobile.constantcapybara1.chatgpt.site

## 이용 방법

1. 학생 등록 없이 바로 시작합니다. 기본으로 펼쳐진 1~10번 문장을 고치거나 선택하세요. 실명·학교·연락처는 문장에 입력하지 마세요.
2. 읽기 속도, 반복(기본 두 번), 수동/자동 진행 방식을 고르고 시작합니다. 기본은 수동 진행이며 다 썼어요를 눌러 다음 문장으로 갑니다. 자동 진행에서는 문장 사이 쓰는 시간을 선택합니다. 지금 읽는 문장과 원래 문제 번호를 크게 표시하며, 필요하면 문장 가리기를 켤 수 있습니다. ‘현재 문장 다시 읽기’는 그 문장만 한 번 다시 읽습니다. 쓰는 시간 중에 누르면 쓰는 시간을 다시 주고 다음 문장으로 이어갑니다. 일시정지 중 눌렀다면 다시 읽기 후 일시정지 상태로 돌아갑니다. 읽기가 모두 끝난 뒤에도 마지막 문장을 다시 들을 수 있으며 부모 확인 내용은 유지됩니다.
3. 종이에 받아쓴 뒤 부모가 잘했어요/다시 연습/미확인을 선택하고 저장합니다.
4. 학습 기록에서 부모 확인을 수정할 수 있습니다. 가장 최근의 직접 확인 결과가 ‘다시 연습’이면 오답노트에 표시합니다.
5. 설정에서 선택적인 보호자 로그인·동기화, 백업·복원·기록 삭제·홈 화면 추가 방법을 확인합니다.

새 연습은 가족 공용으로 저장합니다. 예전에 학생별로 저장한 자료는 삭제하지 않고 모든 학습 기록에서 함께 표시합니다. 이전 학생의 오답 재연습은 해당 이전 기록 분류를 유지합니다. 공개 주소는 사용자 요청에 따라 유지하며 앱 자체에서 타인의 기기 기록을 공유하지 않습니다.

## 문제 묶음·복습·완료 스티커

- 문제 묶음: 편집란의 10문장과 묶음 이름을 저장합니다. 저장은 현재 문제도 함께 보관하며, 묶음을 불러와도 과거 기록은 바뀌지 않습니다. 최대 50개. 묶음 삭제는 현재 문제/기록을 지우지 않습니다.
- 오답 먼저 복습: 부모가 ‘다시 연습’으로 확인한 문장 중 최대 3개를 따로 연습합니다. 오늘의 문제 목록을 덮어쓰지 않습니다. ‘오늘 문장 연습하기’를 누르면 복습 기록을 저장한 뒤 원래 선택한 문제로 이어갑니다. 이전 학생 자료는 원래 기록 분류를 유지합니다.
- 완료 스티커: 수동 모드의 마지막 ‘다 썼어요 · 연습 완료’, 또는 자동 읽기 종료 후 직접 ‘오늘 연습 완료’를 눌러야 완료로 표시합니다. 이후 기록 저장 시 하루 한 개 스티커를 보관합니다. 중간 종료와 과거 자료에는 임의의 완료 표시를 하지 않습니다. 스티커는 정답 점수와 관계없습니다.
- 같은 연습 다시 듣기나 완료 버튼 중복 누르기로 스티커/기록을 중복 생성하지 않습니다. 스티커 날짜는 기기의 현지 시간으로 표시합니다.
- 문제 묶음과 완료 상태는 백업에 포함되며 기존 버전 백업도 가져올 수 있습니다. 예전 자료의 문제 묶음은 비어 있고 완료 여부는 미완료로 해석합니다.
- 인쇄 기능은 제공하지 않습니다.

## 저장 방식

- 로그인 없이도 이용할 수 있으며 기록은 현재 브라우저에만 저장됩니다. 브라우저 데이터를 지우거나 비공개 모드를 닫으면 기록을 잃을 수 있습니다.
- 보호자 ChatGPT 로그인 후에는 Sites가 제공한 계정 식별자별 D1 저장소를 사용합니다. 같은 계정으로 다른 기기에서 열거나 ‘최신 기록 불러오기’를 눌러 기록을 이어갑니다. 로그인은 보호자가 합니다.
- 모든 DB 조회/수정은 서버가 주입한 사용자 ID로 구분합니다. 익명 서버 저장은 거부하고 클라이언트가 보낸 소유자 ID는 사용하지 않습니다.
- 다른 기기에서 변경한 내용을 오래된 화면으로 저장하면 409 충돌을 안내합니다. 저장하지 않은 내용을 확인한 뒤 최신 기록을 불러오세요.
- 이 버전의 클라우드 자료는 Python 앱 SQLite와 자동 연동되지 않습니다.
- 과거 체험 기록은 그대로 두고, 로그인 후 ‘기기 기록을 내 계정으로 가져오기’를 눌렀을 때만 옮깁니다. 중복 가져오기는 중복 학생/기록을 만드므로 확인 메시지를 확인하세요.
- 계정별 기존 자료 분류 최대 30개·기록 1,000회·문제 묶음 50개, 자료 900KB, 요청/백업 1MB입니다. 백업 후 오래된 기록을 삭제할 수 있습니다.
- 로그인 자료 전체 삭제는 계정의 학습 자료를 비우고 수정 충돌 방지용 계정 키/버전만 남깁니다. 다른 계정 자료에는 영향을 주지 않습니다.
- 익명 자료 전체 삭제는 현재 체험 자료와 구버전 체험 자료를 지웁니다. 계정 자료를 삭제해도 다른 기기에 남은 익명 자료나 다운로드한 백업은 삭제되지 않습니다.

## 개인정보 및 음성

별명·수정 문장·부모 확인 결과·연습 날짜만 저장합니다. 사진·녹음·연락처는 받지 않습니다. 계정의 이메일을 학습 DB에 저장하지 않습니다. 기록을 서비스 로그나 소스 저장소로 보내지 않습니다.

TTS는 기기의 Web Speech API 한국어 음성을 사용합니다. 기기 설정에서 한국어 읽기 음성을 설치하세요. 기기의 음성 제공업체가 문장을 처리하거나 인터넷이 필요할 수 있습니다. 민감한 문장은 입력하지 마세요.

홈 화면 추가는 Android Chrome 메뉴 또는 iPhone/iPad Safari 공유 메뉴에서 가능합니다. 인터넷 연결이 필요한 웹앱이며 앱스토어 APK/IPA나 오프라인 앱은 아닙니다.

## 개발 및 배포

Node.js 24 이상을 권장합니다(테스트에 node:sqlite 사용). 앱 빌드는 외부 npm 패키지 없이 실행합니다.

```bash
npm run build
npm test
node --check web/app.js
node --check web/client.js
node --check web/player.js
node --check worker/api.js
git diff --check
```

- web/: HTML·CSS·브라우저 코드, Worker에서도 재사용하는 자료 검증.
- worker/api.js: 인증된 D1 API. /api/account와 /api/data만 제공합니다.
- drizzle/0000_family.sql: 계정별 자료 스키마. 배포 시 Sites가 마이그레이션을 적용합니다.
- scripts/build.mjs: 정적 파일과 API를 단일 dist/server/index.js로 묶고 배포 manifest를 복사합니다.
- .openai/hosting.json: 기존 Sites ID, D1 DB 바인딩, drizzle/ 마이그레이션. 서버 배포이므로 static 항목이 없습니다.
- tests/: 자료 검증/이관·학생 분리·백업·실제 SQLite SQL·HTTP 요청/응답·저장 충돌·브라우저 저장 실패·TTS 대역 테스트.

배포 파일에는 .openai/hosting.json, dist/server/index.js, 마이그레이션 SQL을 포함합니다. 소스와 정확히 일치하는 Git 커밋을 Sites에 저장하고 기존 사이트의 공개 접근 정책으로 배포합니다. 실제 기기 음성, 홈 화면 설치, 로그인 왕복은 실제 태블릿/휴대폰에서 추가 확인해야 합니다.
