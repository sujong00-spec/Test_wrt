# 변경 이력

## 1.2.0

- 앱 이름을 ‘기량이의 받아쓰기 공부’로 변경. 시작/완료 안내와 홈 화면 앱 이름도 반영.
- 기본 수동 진행: 문장을 들은 후 ‘다 썼어요’를 눌러 이동하며 마지막 문장은 직접 완료를 누름. 기존 시간 기반 자동 진행은 선택으로 유지.
- 이름을 붙인 10문장 문제 묶음 저장·수정·불러오기·삭제, 백업/복원 지원.
- 부모가 표시한 오답 중 최대 3문장 복습 후 오늘 문제로 이어가기. 오늘의 10문장은 유지.
- 끝까지 연습한 뒤 저장한 날에 하루 한 개 완료 스티커. 부모 확인 전 정답을 추측하지 않으며 중단한 연습·과거 기록에 임의 보상을 만들지 않음.
- 기존 JSON 자료에 묶음/완료 필드를 하위 호환 방식으로 추가. D1 스키마와 기존 저장 키는 유지.
- 인쇄 기능은 추가하지 않음. GitHub 업로드는 하지 않음.

## 1.1.1

- 현재 문장만 다시 읽기 추가. 재생·쓰기 대기·일시정지·완료 후에 현재 문장을 한 번 다시 읽으며 진행 순서와 기존 기록을 유지.
- 쓰기 대기 중 다시 읽으면 쓰는 시간을 다시 제공. 취소된 음성의 오래된 콜백은 다음 문장으로 넘어가지 못하도록 무효화.
- 완료 후 다시 읽어도 부모 확인 입력을 초기화하거나 새 기록을 만들지 않음.
- 선택한 원래 문제 번호가 쓰기 대기 안내에도 일관되게 표시되도록 수정.

## 1.1.0

- 우리집 가족 공용 모드: 학생 등록·선택·이름/사용자 관리 화면 제거, 등록 없이 바로 연습.
- 로그인·동기화는 선택 기능으로 설정에 이동. 기존 학생/학습 기록은 삭제하지 않고 기록·오답노트에서 계속 제공.
- 현재 읽는 문장과 원래 문제 번호를 크게 표시. 선택적으로 문장 가리기 제공.
- 1~10번 문장 편집란을 기본으로 펼치고 상단 바로 읽기 버튼 제공.
- 가족 공용 기록은 첫 저장 시 자동 생성하며 기존 데이터/스키마와 호환 유지.
- 사용자 요청에 따라 공개 주소는 유지하고 GitHub에는 업로드하지 않음.

## 1.0.2

- 카카오톡 등 앱 내 브라우저의 음성 제한 안내 및 Android Chrome 열기 버튼 추가.
- 브라우저 API 미지원·음성 목록 준비 지연·한국어 음성 준비를 구분해 기기의 설치 상태를 잘못 단정하지 않도록 수정.
- 음성 다시 확인 및 앱 복귀 시 음성 상태 갱신, API가 없는 브라우저의 안전한 중지 처리.

## 1.0.1

- 브라우저의 fetch 호출 시 올바른 전역 객체 연결을 유지해 ‘연결이 끊겼어요’로 표시되던 초기 연결 실패 수정.
- 초기 연결 실패 시 기존 기기 기록을 유지하며 ‘다시 연결’ 제공.
- 서버 요청 예외를 무조건 인터넷 장애로 표현하지 않도록 안내 개선.
- 브라우저 네이티브 함수의 호출 객체 검증을 재현하는 회귀 테스트 추가.

## 1.0.0

- 공개 접근과 보호자 ChatGPT 로그인 지원.
- 계정별 D1 자료 저장과 여러 기기에서 불러오기, 저장 버전 충돌 감지.
- 익명 사용자의 브라우저 체험 저장 유지 및 구버전 기록 명시적 가져오기.
- 학생 별명 수정/삭제, 기록 재확인/삭제, 최근 확인 결과 기반 오답 복습.
- JSON 백업·검증·기존 자료를 유지하는 가져오기.
- 홈 화면 추가 안내와 웹앱 manifest, 한국어 개인정보 안내.
- 기본 두 번 한국어 읽기·속도·반복·쓰기 시간·일시정지/종료 유지.
- OCR/사진 업로드/자동 채점은 제외.
