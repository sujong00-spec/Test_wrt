# 또박또박 우리집 배포판 운영 규칙

- 모든 사용자 화면과 오류 안내는 자연스러운 한국어로 작성한다. MIT LICENSE와 원본 zackzou 저작권 고지를 유지한다.
- 사용자가 공개 배포를 명시적으로 요청했다. 기존 Sites 프로젝트 ID와 주소를 유지하며 공개 접근 정책은 요청 범위 안에서 변경할 수 있다.
- 원본 Python 프로젝트는 상위 Python 프로젝트에 보존한다. 이 저장소는 모바일 배포용 Worker/브라우저 구현이다.
- 1단계만 제공한다. 아이 사진·녹음·OCR·자동 채점·가짜 AI 결과를 추가하지 않는다. 실명·학교·연락처를 입력하도록 요구하지 않는다.
- 공개 페이지는 익명 체험을 허용한다. 익명 기록은 해당 브라우저에만 저장한다. 로그인한 보호자의 자료는 Sites가 주입한 oai-authenticated-user-id로 구분하고 모든 DB 쿼리에 소유자 조건을 넣는다.
- 클라이언트가 보낸 소유자 ID를 신뢰하지 않는다. 외부 노출 API는 인증·입력 검증·교차 사이트 요청 방지·용량 한도를 검증한다. 이메일을 DB 키로 쓰지 않는다.
- web/data.js는 공유 자료 검증과 변환, worker/api.js는 D1 API, web/client.js는 브라우저/계정 저장 전환, web/app.js는 화면 제어를 담당한다.
- web/가 원본 프런트엔드이며 dist/는 scripts/build.mjs가 생성하는 Worker 배포 결과다. generated 파일을 직접 수정하지 않는다.
- D1 테이블은 drizzle/의 스키마 전용 SQL로 생성하며 요청 처리 중 CREATE/ALTER 하지 않는다. 적용된 마이그레이션은 수정하지 말고 다음 파일을 추가한다.
- 기록 사본·미확인 상태·부모 직접 확인을 유지한다. 클라우드 저장은 revision 기반 충돌 검사로 다른 기기의 최신 기록을 덮어쓰지 않게 한다.
- 기존 체험 기록은 자동 업로드하지 않는다. 사용자의 가져오기 동작과 확인 후 서버에 저장한다. 백업 자료는 검증하며 계정 식별자를 내보내지 않는다.
- 공개 소스/배포 파일에 개인정보·비밀키·실제 백업을 넣지 않는다. 로그에 학습 자료와 사용자 식별자를 출력하지 않는다.
- npm run build 후 npm test, 구문 검사, git diff --check를 수행한다. DB 테스트는 실제 SQLite 기반 D1 대역으로 계정 분리·충돌·삭제·입력 거부를 확인한다.
- 관리형 Sites 환경에 cua_repl.js 도구가 없으면 별도 브라우저 서버나 우회 브라우저 제어를 만들지 않는다. 해당 검증 한계를 보고하고 가능한 테스트와 정상 배포 확인을 진행한다.

- 현재 UI는 가족 공용 모드다. 학생 등록·선택·이름 관리 화면을 되살리지 않는다. 새 연습은 FAMILY_ID로 저장하고 이전 학생 자료는 유지한다.
- 읽는 문장과 원래 번호는 기본으로 보여주고 문장 가리기는 선택 기능이다. 1~10번 편집란은 기본으로 펼친다.
- GitHub 업로드는 사용자가 명시적으로 요청한 저장소와 범위에서만 수행한다. 개인정보·학습 기록·비밀키는 제외한다.

- 현재 앱은 한 명용 ‘기량이의 받아쓰기 공부’다. 이 이름은 사용자가 제목으로 지정한 브랜딩이며 추가 개인정보를 수집하지 않는다.
- 기본 진행은 수동이다. 모든 문장을 읽고 사용자가 마지막 완료를 눌러야 완료 스티커를 부여하며 부모 확인 전 점수를 추측하지 않는다.
- 문제 묶음(packs)·completed/kind 필드는 기존 JSON과 하위 호환하고 D1 마이그레이션을 불필요하게 추가하지 않는다. 인쇄 기능은 제외한다.
