# 우리집 받아쓰기 기능 검토

시중 도구의 공식 기능 안내를 비교해 가정용 종이 받아쓰기에 적용할 아이디어를 정리했습니다. 아래 항목은 개선 제안이며, 1.1.1에 모두 구현한 기능 목록은 아닙니다.

## 참고한 도구

- [Spelling.Live](https://spelling.live/help/welcome): 직접 입력한 학교 문제, 수정 가능한 주간 연습 계획, 취약 단어 우선 복습, 출력용 연습 묶음을 안내합니다.
- [Spelling Shed](https://www.spellingshed.com/en-gb/): 단계별 철자 학습과 주중 반복 활동을 제시합니다. 영어의 철자 규칙을 그대로 가져오기보다 한글의 받침·띄어쓰기·문장부호 등 부모가 정한 분류에 적용할 수 있습니다.
- [Google Read Along](https://readalong.google/): 필요할 때 도움을 주고 별·배지로 읽기를 격려합니다. 우리 앱에서는 실제로 완료한 연습에 대한 작은 보상을 참고할 수 있습니다.

## 다음 개선 우선순위 — 우리집 사용 관점의 제안

1. **수동 다음 문장**: ‘다 썼어요 → 다음 문장’. 고정된 5/10/20초를 기다리거나 쫓기지 않고 아이가 쓰는 속도에 맞춥니다. 현재 자동 진행도 선택 사항으로 유지합니다.
2. **학교 문제 묶음 저장**: ‘1주차 받아쓰기’, ‘받침 연습’처럼 10문장 묶음을 저장·불러옵니다. 오늘 문제를 바꿔도 지난 묶음을 다시 입력하지 않습니다.
3. **오답 3문장으로 시작**: 부모가 다시 연습으로 확인한 문장 중 일부만 다음 연습의 첫 단계로 제안합니다. 기존 오답노트에 이미 있는 자료를 활용합니다.
4. **짧은 연습과 작은 보상**: ‘오늘 5문장 끝!’처럼 완료를 격려합니다. 부모 확인 전에는 정답을 추측하거나 ‘전부 맞았어요’라고 표시하지 않습니다.
5. **출력용 연습지**: 번호와 빈 쓰기 칸을 넣은 A4 한 장, 부모용 정답지 분리. 종이 중심 사용을 유지합니다.

우선순위는 우리집 사용 목적에 맞춘 구현 판단이며, 특정 기능이 학습 효과를 보장한다는 뜻은 아닙니다. 사용자 등록·랭킹·다른 가족과 공유하는 기능은 현재 가족 공용 흐름에 추가하지 않습니다.

## 이번 1.1.1에서 반영한 내용

현재 문장만 다시 읽기, 쓰기 대기 시간 다시 제공, 일시정지 복귀, 연습 완료 후 마지막 문장 재생, 부모 확인 입력 보존. 나머지는 후속 요청 시 검토합니다.
